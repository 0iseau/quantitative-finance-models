# Quantitative Finance Models

Python project for implementing financial models studied in coursework.

Planned models and methods for master's-level quantitative portfolio management:

```text
models/
  pricing/      CAPM, APT, Black-Scholes, binomial trees, Heston
  risk/         Value at Risk, Expected Shortfall, GARCH, factor risk models
  simulation/   Monte Carlo, historical simulation, geometric Brownian motion, bootstrap
```
